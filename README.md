# Neural Forge

Ein visueller No-Code-Editor für KI-Workflows – inspiriert vom Bausteinprinzip
von MCreator.

## Funktionen

- KI-Workflows aus Eingaben, Modellen, Agenten, Wissen und Logik aufbauen
- Bausteine auf einer visuellen Arbeitsfläche verschieben und konfigurieren
- Vorgefertigte Assistenten-, Analyse- und Recherche-Workflows verwenden
- Projekte automatisch lokal speichern und als JSON exportieren
- Abläufe in einem integrierten Testlabor simulieren

## Entwicklung

```bash
npm install
npm run dev
```

Für einen Produktions-Build:

```bash
npm run build
```
